# LV-01 integrated cohort evidence

`npm run verify:integrated-cohort` is the disposable-Local acceptance harness for BRIEF-SC02.
It proves one frozen 120-project identity set through the existing intake, review, participant,
controlled-publication, stored-feed, and public-renderer authorities. It is distinct from the
component-only release evaluator, annual publication verifier, and annual renderer fixture.

The manifest is built before project mutation and contains 100 package-origin and 20 standardized-
form-origin members. Form members are materialized by `materializeFormIntakeWorkbook`; all members
then share the normal server analysis, Admin-reference reconciliation, commit-intent, authoritative
revalidation, metadata staging, media validation, private staging, and completed-batch path. One
separate synthetic Admin reference workbook covers all 120 members. The cohort uses five explicitly
synthetic program families (IT, Engineering, Aviation, Food Technology, and a future-program value),
five disciplines, five industries, five years, all three layouts, ordinary gallery images, and
text-bearing gallery images with approved full text.

The verifier refuses a dirty working tree and records its exact committed HEAD. It checks exact set
equality—not only counts—at every major phase. Review runs in 50/50/20 bounded preflight/execution
groups. Participant previews are generated through the atomic preview/notification repository,
sent only to an in-memory Local capture transport, and confirmed through the participant authority.
The real controlled-publication service runs sequentially with execution target `local`, including
writer, immutable ledger, media promotion, head/version, audit, and idempotency behavior.

The final stored feed bytes are copied to an OS-temporary evidence directory and supplied directly
to the maintained Duda HTML/CSS/JavaScript browser harness. No second feed is generated. Exact-feed
mode adds 320 px coverage and binds renderer evidence to both the manifest hash and feed hash.
